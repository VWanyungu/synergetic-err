## **Database folder**

This folder contains database setup and access files

The utils folder contains file for accessing the cache and main database
    - cache.js creates a Cache class containing methods for set, get and del'
    - database.js created 2 base classes, Users and Token for interacting with each respectively. More classes for distinct modules can be added here e.g Orders for managing orders in the database

cacheSetup.js initiates a new cache db in Upstash
dbSetup.js uses knex query builder to initiate the database as defined in knexfile.js

## **Middlewares folder**

This folder contains all version specific middlewares

token.js check ensure that each request is accompanied by a token and sets rues for which paths are exempt

## **Migrations folder**

This folder contains all knex generated db migration files. These define db configuration and help with version control of the database. It's autogenerated by knex. Default migration files set up users and token in the database

## **routers folder**

This folder contains all Express router files (handle logic for domain specific paths e.g usersRouter handle all users endpoints). 

## **Seeds folder**

This folder contains all knex generated seed files. These populate data to the database

## **Utils folder**

This folder contains utility function files

1. checkCache.js - checks whether a token has been blacklisted (When a use logs out, their token is blacklisted and recorded in the database as such)
2. generateJwtToken.js - generates a jwt token for a logging in user
3. hashPassword.js - uses bcrypt to hash password during sign up or password reset
4. sendMail.js - sends emails
5. validation.js - contains validation schemas
