An Admin has every Risk Officer permission. Start with the [Risk Officer guide](/roles/risk-officer/overview) for those tasks.

## What is specific to Admins

- **Manage Admin accounts.** Only you can edit or deactivate an Admin, or give someone the Admin role.
- **Change a user's email.** Risk Officers cannot.

<Note>Changing a user's role, department or division signs them out so the change applies. They need to sign in again to continue.</Note>
