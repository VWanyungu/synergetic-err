An Admin has every Risk Officer permission: all departments, editing any risk, deciding archive requests and managing users. Start with the [Risk Officer guide](/roles/risk-officer/overview) for those tasks.

## What is specific to Admins

- **Manage Admin accounts.** Only you can edit or deactivate an Admin, or give someone the Admin role.
- **Change a user's email.** Risk Officers cannot.
