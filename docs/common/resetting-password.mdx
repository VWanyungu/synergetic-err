---
title: "Resetting your password"
---

{/* Use this when you have forgotten your password, or when you were given a default password on a new account. */}

<Steps>
  <Step title="Ask for a link">
    On the login page choose **Forgot password?**, enter your work email and submit.
  </Step>
  <Step title="Open the email">
    The link is valid for **15 minutes** and works once. The page gives the same message whether or not the email has an account, so check your inbox (and spam) rather than retrying immediately.
  </Step>
  <Step title="Choose a new password">
    Enter a new password and submit.
  </Step>
  <Step title="Log in">
    Return to the login page and sign in with the new password.
  </Step>
</Steps>

{/* <Tip>If you see **This link has expired**, request a new one. Each request replaces the need for the old link.</Tip> */}

<Note>Accounts created by an Admin start with a default password. Reset it the first time you sign in.</Note>
